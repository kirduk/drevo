# Папка для фотографий сайта

Сюда добавляйте изображения проектов мебельной фабрики «Мировое Древо».

## Как добавить фото на сайт

1. Положите файл в эту папку (`public/photos/`).
   Поддерживаются форматы: **JPG**, **PNG**, **WebP**, **SVG**.

2. Откройте `gallery.json` и добавьте запись:

```json
{
  "file": "my-kitchen.jpg",
  "title": "Кухня для загородного дома",
  "category": "Кухни"
}
```

3. Закоммитьте изменения и запушьте в репозиторий — Amvera автоматически пересоберёт сайт.

## Пример gallery.json

```json
{
  "images": [
    {
      "file": "kitchen-01.jpg",
      "title": "Кухня «Борneo»",
      "category": "Кухни"
    }
  ]
}
```

Поле `category` необязательно.
